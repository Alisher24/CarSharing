# CarSharing

Сервис каршеринга для Бишкека: Go backend, React frontend, расчёты в кыргызских сомах (KGS).
Планируются электрические, бензиновые, дизельные, гибридные и газовые автомобили.

Репозиторий: [Alisher24/CarSharing](https://github.com/Alisher24/CarSharing) (public).

T00 добавляет ignore-файлы, правила форматирования, шаблон PR, локальный hook
проверки секретов, GitHub Actions `Repository checks` и Dependabot для Actions.
Приложение и Docker Compose ещё не реализованы; инструкция запуска появится в T02.

Основная ветка — `master`. Одна задача выполняется в ветке `codex/Txx-short-name`
и оформляется отдельным PR. Начальный коммит пустого репозитория — однократное исключение.

Каталог `docs/` содержит локальные материалы планирования. По решению владельца он полностью
исключён из Git и Docker-контекста: его содержимое не входит в clone репозитория.

Подготовка рабочего места, проверки и порядок PR описаны в [CONTRIBUTING.md](CONTRIBUTING.md).
GitHub secret scanning и push protection включены; серверные права Actions ограничены чтением.
